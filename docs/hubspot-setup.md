# HubSpot の設定手順

サイトのフォーム（資料請求・無料相談）と日程調整を HubSpot につなぐ手順。無料プランで足りる。設定が終わるまで、フォームは送信せずに「（設定前のため送信されません）」と表示する。

## 1. アカウントを作る

1. https://www.hubspot.jp/ から無料で登録する（メールは hayato.ogayu@gmail.com）
2. 右上のアカウント名を開き、表示される「アカウントID」（数字）を控える → これが **ポータルID**

## 2. 「ご相談内容」のプロパティを作る

無料相談フォームの「ご相談内容（選択）」を受けるための項目。ほかの項目（会社名・名・メール・電話番号・メッセージ）は HubSpot に最初からある。

1. 設定（歯車）→ データ管理 → プロパティ → 「コンタクトプロパティ」→ プロパティを作成
2. ラベル：`ご相談内容`、内部名：**`consult_type`**（必ずこの名前）
3. フィールドタイプ：ドロップダウン選択。選択肢は次の4つを、ラベルも内部の値も同じ文字で入れる
   - ひとりめ代行プラン
   - ひとりめサポートプラン
   - スポットプラン
   - まだ決まっていない

## 3. フォームを2つ作る

マーケティング → フォーム → フォームを作成 →「埋め込みフォーム」。見た目はサイト側で作っているので、HubSpot 側は項目がそろっていればよい。

| フォーム名 | 入れる項目（内部名） |
|---|---|
| 資料請求 | 会社名 `company`、名 `firstname`、Eメール `email`、電話番号 `phone` |
| 無料相談 | 上の4つ ＋ ご相談内容 `consult_type`、メッセージ `message` |

- 「名」にはサイトの「お名前」（姓名をまとめたもの）がそのまま入る。姓の項目は入れない
- 各フォームの「オプション」で、送信後の通知メールの宛先を hayato.ogayu@gmail.com にする
- 公開したら、フォームの編集画面の URL の末尾（`…/editor/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/…` の英数字）を控える → これが **フォームのID（GUID）**

### 自動返信メール

各フォームの「オプション」→「フォローアップメール」（自動返信）を設定する。

- 資料請求：お礼と、サービス資料（PDF）のリンク。サイトには「1営業日以内に、メールで資料をお送りします」と書いてあるので、資料ができるまでは手動で送ってもよい
- 無料相談：お礼と「日程はカレンダーからお選びいただけます。選びそびれた場合は、2営業日以内に候補をお送りします」

## 4. 日程調整（ミーティング）を作る

1. セールス（またはライブラリ）→ ミーティング → ミーティングリンクを作成 →「1対1」
2. 名前：`無料相談（60分）`、所要時間：60分、場所：Google Meet か Zoom
3. 受け付ける曜日と時間帯、直前の予約を受けない時間（例：2営業日前まで）を決める
4. Google カレンダーと連携しておくと、予定が入っている時間は自動で外れる
5. 保存して、予約ページのリンク（`https://meetings.hubspot.com/…`）を控える

無料相談フォームの送信が終わると、サイトがこのカレンダーを埋め込んで表示する。名前・メール・会社名は、フォームで入力したものが最初から入る。

## 5. サイトに設定を入れる

`_build/forms.js` の先頭の4行に、控えた値を入れる（`js/forms.js` は書き出し先なので直接は直さない）。

```js
var HUBSPOT_PORTAL_ID = "12345678";
var HUBSPOT_FORM_DOWNLOAD = "資料請求フォームのGUID";
var HUBSPOT_FORM_CONSULT = "無料相談フォームのGUID";
var HUBSPOT_MEETING_URL = "https://meetings.hubspot.com/…";
```

そのあと書き出して確認する。

```bash
python3 _build/build.py && python3 _build/validate.py
```

## 6. 送信を試す

1. 公開したサイトから、両方のフォームを自分で1回ずつ送る
2. HubSpot の「コンタクト」に入っていること、通知メールと自動返信が届くことを確かめる
3. 無料相談では、送信後にカレンダーが出て予約できることを確かめる
4. 試しに入れたコンタクトは削除しておく

送信で「送信できませんでした」と出るときは、ブラウザの開発者ツールの Console に HubSpot のエラーが出ている。多いのは次の2つ。

- 項目の内部名が違う（`consult_type` の綴り、ドロップダウンの値の文字の違い）
- 同意（プライバシーの同意）の扱い：HubSpot 側で「データプライバシーと同意」をオンにしていないと、同意の情報を受け付けないことがある。その場合は、フォームの「データプライバシーと同意」で「処理への同意を求める」にするか、`_build/forms.js` の `legalConsentOptions` を送らないように直す
