# フォームと日程調整の設定手順（Google）

サイトのフォーム（資料請求・無料相談）と日程調整を、Google アカウント（hayato.ogayu@gmail.com）だけで動かす手順。すべて無料。

できあがる仕組み：

| やること | 仕組み |
|---|---|
| フォームの内容を記録 | スプレッドシートの「資料請求」「無料相談」シートに1行ずつ |
| 運営者への通知 | 送られるたびに hayato.ogayu@gmail.com へメール |
| 送った人への自動返信 | あなたの Gmail から受付メール |
| 日程調整 | 自動では出さない。運営者が予約ページのリンクをメールで個別に送る |
| 予約の記録 | 「予約」シートに1行ずつ（1時間ごとに確認） |
| リマインド | 相談の前日（24時間前）に、相手へ日時と Meet のリンクを送る |

設定が終わるまで、フォームは送信せずに「（設定前のため送信されません）」と表示する。

## 1. 予約ページを作る（Google カレンダー）

1. https://calendar.google.com を開き、左上の「作成」→「予約スケジュール」
2. タイトル：**無料相談（60分）**（「無料相談」の語を必ず入れる。リマインドはこの語で予定を見分ける）
3. 予約の長さ：60分
4. 受け付ける曜日と時間帯を入れる
5. 「予約可能期間の調整」で、直前の予約を受けない時間（例：2日前まで）と、1日の上限を決める
6. 「会議」は Google Meet、「予約フォーム」は名・姓・メールのまま
7. 保存したら、カレンダーの予定をクリック →「共有」から次の2つを控える
   - **予約ページのリンク**（`https://calendar.app.google/…`）→ 無料相談の申し込みがあったら、このリンクを日程調整のメールに貼って送る

## 2. スプレッドシートとスクリプトを作る

1. https://sheets.new で新しいスプレッドシートを作り、名前を「ひとりめマーケ_フォーム」にする
2. メニューの「拡張機能」→「Apps Script」
3. 最初から入っている `function myFunction() {…}` を全部消して、リポジトリの `gas/Code.gs` の中身を貼り付ける
4. 先頭の `CONFIG` を書き換える
   - `SHEET_ID`：このスプレッドシートの ID（URL の `/d/` と `/edit` の間）
   - `DOC_URL`：サービス資料（PDF）の共有リンク。まだ無ければ空のままでよい（自動返信は「1営業日以内にお送りします」になる）
5. 左の「サービス」の ＋ →「Google Calendar API」→「追加」（リマインドに Meet のリンクを載せるため）
6. 💾 で保存する

## 3. 初期設定を実行する

1. 上の関数の選択で **setup** を選び、「実行」
2. 「承認が必要です」→ 自分の Google アカウントを選ぶ
3. 「このアプリは Google で確認されていません」と出たら、「詳細」→「ひとりめマーケ（安全ではないページ）に移動」→「許可」。自分で作ったスクリプトなので問題ない
4. 実行ログに「準備ができました」と出て、スプレッドシートに「資料請求」「無料相談」「予約」の3つのシートができていれば完了。リマインド用の1時間ごとのトリガーもここで作られる

## 4. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択（⚙）で「ウェブアプリ」
3. 次のユーザーとして実行：**自分**、アクセスできるユーザー：**全員**
4. 「デプロイ」→ 表示される **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を控える

「全員」にしても、見えるのはフォームの受け取り口だけで、スプレッドシートやメールは見えない。

あとで `Code.gs` を直したときは、「デプロイ」→「デプロイを管理」→ ✏ →「バージョン：新バージョン」→「デプロイ」で反映する（URL は変わらない）。

## 5. サイトに設定を入れる

ウェブアプリの URL を Claude に渡す（または `_build/forms.js` の先頭に入れて、書き出す）。`BOOKING_URL` は空のままにする（入れると、無料相談の送信後に予約カレンダーが自動で出る）。

```js
var FORM_ENDPOINT = "https://script.google.com/macros/s/…/exec";
var BOOKING_URL = "";
```

```bash
python3 _build/build.py && python3 _build/validate.py
```

## 6. 送信を試す

1. 公開したサイトから、資料請求と無料相談を自分で1回ずつ送る
2. 確かめること
   - スプレッドシートに1行ずつ入る
   - hayato.ogayu@gmail.com に通知が2通届く
   - 送り先に入れたメールアドレスに自動返信が届く
3. 予約を入れたら、1時間以内に「予約」シートに記録される。リマインドは相談の24時間前に届く（試すときは、翌日の枠を予約する）
4. 試しの行と予約は消しておく

## 補足

- 自動で送れるメールは1日100通まで（無料の Google アカウントの上限）
- 迷惑な送信対策として、人には見えない入力欄が埋まっている送信は捨てる
- 同じメールアドレスから60秒以内に送り直された場合は、記録はするがメールは送り直さない
- 予約を受けたときの相手への確認メールと、あなたへの通知は、Google カレンダーが自動で送る
